# SynkaCore

Middleware industrial para coleta, normalização, persistência e exposição de dados de chão de fábrica. Desenvolvido em Java com Spring Boot, com foco em resiliência operacional e observabilidade desde a fundação.

---

## O que é o SynkaCore

O SynkaCore atua como ponte entre equipamentos industriais (camada OT — Operational Technology) e sistemas corporativos de gestão (camada IT — Information Technology). Ele coleta dados de CLPs e sensores via protocolos industriais, normaliza para um formato unificado, persiste em banco de séries temporais e expõe via API REST.

O projeto é construído software-first: a camada de software é validada e estabilizada antes da integração com hardware real. Dados simulados são usados para desenvolvimento e validação de resiliência até que protocolos reais sejam integrados nas versões subsequentes.

## Arquitetura

O projeto é organizado como um projeto Maven multi-módulo com quatro módulos. A regra de dependência é unidirecional: camadas externas conhecem as internas, mas o Domain nunca depende de tecnologia externa.

```
synkacore-domain          (tipos puros, contratos, configurações, validações)
       ↑
synkacore-infrastructure  (PostgreSQL/TimescaleDB, protocolos industriais)
       ↑
synkacore-collector       (worker de background, resiliência, coleta contínua)
synkacore-api             (API REST, endpoints HTTP, health check real)
```

### synkacore-domain

Contém apenas tipos puros e contratos. Não depende de nenhuma tecnologia externa além do binding de configuração e das anotações de validação.

- `SensorReading.java` — record imutável representando uma leitura de sensor
- `contract/ProtocolReader.java` — interface genérica para qualquer protocolo industrial
- `settings/PostgresSettings.java` — configurações tipadas do banco de dados, com validação obrigatória no startup via `@Validated`
- `settings/OpcUaSettings.java` — configurações tipadas para OPC UA

### synkacore-infrastructure

Implementações concretas de tecnologia.

`persistence/`:
- `SensorReadingRepository.java` — grava leituras no TimescaleDB sob a pipeline de resiliência (Resilience4j)
- `SensorReadingQueryRepository.java` — consulta leituras com mapeamento tipado das colunas via `RowMapper`

`protocol/`:
- `OpcUaProtocolReader.java` — implementação OPC UA da interface `ProtocolReader` (Eclipse Milo)
- `ModbusProtocolReader.java` — stub para implementação futura de Modbus TCP

### synkacore-collector

Worker de background com três estados operacionais: CONECTADO, RECONECTANDO e DEGRADADO. Implementa resiliência com Resilience4j (retry + circuit breaker + timeout) e logs estruturados com SLF4J/Logback.

### synkacore-api

API REST com Spring Web.

| Endpoint | Descrição |
|---|---|
| `GET /readings` | Retorna as últimas 100 leituras em JSON |
| `GET /health` | Verifica conectividade real com o banco via SELECT 1 |

## Como executar localmente

### Pré-requisitos

- JDK 25: https://adoptium.net/
- Maven 3.9+: https://maven.apache.org/download.cgi
- Docker: https://docs.docker.com/engine/install/

### Subir infraestrutura

```bash
docker run -d \
  --name synkacore-timescaledb \
  -e POSTGRES_PASSWORD=synkacore \
  -e POSTGRES_DB=synkacore \
  -p 5432:5432 \
  timescale/timescaledb:latest-pg17
```

### Configurar banco

```bash
docker exec synkacore-timescaledb psql -U postgres -d synkacore \
  -c "CREATE EXTENSION IF NOT EXISTS timescaledb;"

docker exec synkacore-timescaledb psql -U postgres -d synkacore -c "
CREATE TABLE IF NOT EXISTS sensor_readings (
    time  TIMESTAMPTZ  NOT NULL,
    tag   TEXT         NOT NULL,
    value NUMERIC      NOT NULL,
    unit  TEXT         NOT NULL
);"

docker exec synkacore-timescaledb psql -U postgres -d synkacore \
  -c "SELECT create_hypertable('sensor_readings', by_range('time'));"

docker exec synkacore-timescaledb psql -U postgres -d synkacore \
  -c "CREATE INDEX IF NOT EXISTS idx_sensor_readings_tag_time ON sensor_readings (tag, time DESC);"
```

### Executar

```bash
cd ~/Synka/SynkaCore
mvn clean install

# Terminal 1
mvn -pl synkacore-collector spring-boot:run

# Terminal 2
mvn -pl synkacore-api spring-boot:run
```
